生成AI支援の設定

分析結果の解釈をGeminiに依頼するための接続設定です。APIキーなしでも、分析結果ページの「AI用テキストをコピー」は使えます。

AIがすること 表示済みの結果を初学者向けに言い換え、次に確認することを提案します。 AIがしないこと モデルを再計算したり、解釈の正しさを保証したりはしません。

APIキーなし結果ページでAI用テキストをコピーし、別のAIへ貼り付けます。

Gemini APIキーあり結果パネル内で解釈を生成し、続けて質問できます。

  • APIキーはページのメモリ内だけに保持され、再読み込みすると消えます。
  • 送信は「解釈を生成」または追加質問を押したときだけです。
  • 履歴保存を要求せず（store=false）、先頭10件の値は既定では送りません。

ブラウザではキーを完全に秘匿できません。利用制限を設定した専用キーを使用してください。

このアプリケーションについて

easyDataScience - ブラウザ機械学習アプリ

easyDataScienceは、ブラウザ上で動作する無料の機械学習Webアプリケーションです。 PyCaret のように複数のモデルを自動比較し、最適なモデルを見つけることができます。 通常のデータ処理と学習はブラウザ内で完結します。生成AI支援を実行した場合だけ、選択した分析文脈が Google Gemini API へ送信されます。

主な特徴

  • 完全ブラウザベース: インストール不要、Webブラウザだけで利用可能
  • データプライバシー: 通常処理は端末内で完結し、生成AIへの送信範囲は利用者が選択
  • AutoML機能: PyCaret のように複数モデルを自動で学習・比較
  • 回帰・分類対応: 連続値予測とカテゴリ分類の両方に対応
  • 画像・音声分類: TensorFlow.js による転移学習で画像分類、Web Audio API で音声分類が可能
  • 日英対応: UI、分析結果の解釈、マニュアルを日本語と英語で切り替え
  • 教育的: 機械学習手法の説明と結果の解釈を提供

使い方・操作方法

基本的な使い方

1
データをアップロード

Excel（.xlsx, .xls）またはCSVファイルを選択してください。ドラッグ＆ドロップにも対応しています。

2
分析タスクを選択

回帰（連続値予測）または分類（カテゴリ予測）を選択します。EDAで事前にデータを把握することもできます。

3
目的変数を選択

予測したい変数（目的変数）を選択すると、自動で前処理とモデル学習が行われます。

4
モデル比較結果を確認

PyCaret のように複数モデルの性能比較表が表示されます。最適なモデルの詳細評価やグラフも確認できます。
