easyDataScience 使い方マニュアル

CSV / Excel の表データによる回帰・分類 AutoML、画像・音声分類、動画分析、保存済みモデルによる予測までを、 初学者でも迷わず進められるように整理したマニュアルです。

1. できること

easyDataScience は、PyCaret のような機械学習ワークフローをブラウザ上で体験できる教育用アプリです。

学ぶ

機械学習入門ガイドで、回帰・分類・評価指標・前処理を図解付きで確認できます。

表データAutoML

CSV / Excel を読み込み、回帰・分類モデルを比較、チューニング、解釈、予測できます。

画像・音声・動画

画像・音声分類に加え、動画のコマ送り、描画、タグ、比較、ポーズ推定を体験できます。

モデル活用

ファイナライズしたモデルを JSON で保存し、予測モードで再利用できます。

プライバシー: 通常のデータ処理と学習はブラウザ内で行われます。生成AI支援を実行した場合だけ、選択した分析文脈が Google Gemini API へ送信されます。

2. 起動方法

公開ページで使う

公開されている easyDataScience のページをブラウザで開きます。インストールは不要です。

表示言語を切り替える

ページ上部の「JP / EN」で、操作画面、結果説明、学習ガイド、マニュアル、生成AI支援を再読み込みなしで切り替えられます。

選択した言語はブラウザに保存され、アプリとマニュアルで共有されます。列名、ファイル名、クラス名、入力値などのユーザーデータは翻訳されません。

ローカルで使う

リポジトリを手元に置いて使う場合は、プロジェクトルートでローカルサーバーを起動します。

python3 -m http.server 8765

ブラウザで http://localhost:8765 を開きます。

グラフ、Excel読込、画像・動画分析のライブラリは必要になった時点でCDNから読み込みます。初回利用時はインターネット接続が必要です。

注意: index.html を直接開くと、ES Modules やデモデータの読み込みが失敗することがあります。

3. 基本操作

  1. データをアップロードする、またはデモデータを読み込む
  2. データプレビューと要約統計量を確認する
  3. 必要に応じて EDA で分布、相関、欠損値を確認する
  4. 目的変数の種類に合わせて「回帰」または「分類」を選ぶ
  5. 目的変数、テストデータ割合、交差検証 Fold 数、特徴量を設定する
  6. モデル比較を開始し、前処理込み交差検証だけで候補を絞る
  7. 必要に応じてチューニングし、最終候補を決める
  8. 選んだモデルについて未使用テストデータを一度だけ開示する
  9. 評価指標、区間、グラフ、解釈結果を見る
  10. 必要に応じてブレンド、スタッキング、ファイナライズを行う。テスト開示後の追加比較は探索的に扱う
  11. predict_model または予測モードで新しいデータを予測する

4. 正しいデータ表の作り方

機械学習では、データの形が結果の信頼性に直結します。読み込み前に、機械が解釈しやすい表へ整えてください。

良い例

面積 築年数 駅距離 部屋数 価格
6512834200
805446100
45251522800
  • 1行目は列名だけにする
  • 2行目以降にデータを入れる
  • 1件のデータを1行にする
  • セル結合を使わない
  • 数値列に単位や「約」などの文字を混ぜない
  • 目的変数を1つ決めておく

5. データ型の考え方

数値変数

価格、売上、年齢、面積、学習時間、テスト点数など。数値を予測したい場合は回帰を使います。

カテゴリ変数

解約する / しない、品種、クラス、合格 / 不合格など。カテゴリを予測したい場合は分類を使います。

画像・音声

画像分類と音声分類では、CSVではなく画像ファイルや音声サンプルを直接使います。

6. デモデータ

手元にデータがない場合は、トップ画面の「デモデータを試す」から読み込めます。

回帰向け

  • regression_demo.csv: 住宅価格データ。面積や築年数から価格を予測します。
  • tips.csv: 食事の合計金額などからチップを予測します。

分類向け

  • classification_demo.csv: 顧客の解約を予測します。
  • iris.csv: 花の計測値から品種を分類します。
  • wine.csv: 化学分析値からワイン品種を分類します。
  • penguins.csv: 体の計測値から種類を分類します。

7. EDA・前処理

探索的データ分析（EDA）

データの分布、相関、欠損値を可視化します。回帰や分類に進む前に、外れ値、欠損、目的変数との関係を確認します。

数値変数 1つ以上

データ前処理

欠損値補完、スケーリング、エンコーディングなど、機械学習に必要な前処理を確認します。AutoML 画面では学習時にも自動前処理が実行されます。

8. 回帰モデル比較（AutoML）

住宅価格、売上、テスト点数、チップ金額など、数値を予測したいときに使います。

目的変数: 数値 数値の目的変数 + 特徴量

操作手順

  1. 目的変数を選ぶ
  2. データの生成過程に合わせ、無作為・グループ非重複・時系列から分割方法を選ぶ
  3. テストデータ割合と交差検証 Fold 数を選ぶ
  4. 使用する特徴量を確認する
  5. 「モデル比較を開始」を押す
  6. 前処理込みCV R2の平均とfold間SDで候補を選ぶ
  7. 最終候補を決めてからテストデータを開示し、R2、MAE、RMSEとブートストラップ区間を確認する

搭載モデル

線形回帰、Ridge回帰、Lasso回帰、決定木、ランダムフォレスト、K近傍法、勾配ブースティング。

9. 分類モデル比較（AutoML）

解約する / しない、品種、合格 / 不合格など、カテゴリを予測したいときに使います。

目的変数: カテゴリ 2〜20種類の目的変数 + 特徴量

操作手順

  1. 目的変数を選ぶ
  2. 二値分類ではAverage Precisionの陽性クラスを確認する
  3. 無作為層化・グループ非重複・時系列から分割方法を選ぶ
  4. テストデータ割合と交差検証 Fold 数を選ぶ
  5. 使用する特徴量を確認する
  6. 「モデル比較を開始」を押す
  7. 前処理込みCV Macro F1の平均とfold間SDで候補を選ぶ
  8. 最終候補を決めてからテストデータを開示し、Macro F1、Accuracy、MCC、クラス別指標、AUC、二値分類のAverage Precision、混同行列を確認する

搭載モデル

ロジスティック回帰、決定木、ランダムフォレスト、K近傍法、ナイーブベイズ、SVM、勾配ブースティング。

クラス不均衡がある場合は、Accuracy だけでなく F1、Precision、Recall、混同行列を確認してください。

10. AutoML ワークフロー

Setup

目的変数、データ構造に合う分割方法、テスト割合、Fold数、特徴量を決めます。

Preprocess

各訓練区画の中だけで欠損処理、One-Hot Encoding、変換、スケーリングを学習します。

Compare

テストデータを封印したまま、前処理込み交差検証で複数モデルを比較します。

Tune

ハイパーパラメータを探索します。

Interpret

特徴量重要度、PDP、学習曲線、SHAP 系の可視化を確認します。

Finalize / Predict

最終モデルを確定し、新しいデータを予測します。

11. 生成AI支援

分析結果ページのフローティングパネルから、結果の読み取りを補助するAI用テキストを作成できます。

APIキーなしで使う

「AI用テキストをコピー」を押すと、要約統計量、分析手法、主要指標、注意点を含む文脈をコピーできます。ChatGPT、Gemini、Claudeなどへ貼り付ける場合は、内容を確認してから利用してください。

Geminiで直接生成する

ページ上部の「生成AI支援」からGemini APIキーを入力すると、安定版gemini-3.7-flashとInteractions APIを使って「解釈を生成」したり、追加質問したりできます。

送信範囲: Google Gemini APIへ送信されるのは「解釈を生成」または追加質問を押した場合だけです。既定では要約統計量、分析手法、主要指標、注意点を送信します。先頭10件のプレビューは設定で明示的に許可した場合だけ追加されます。
  • 回帰・分類では、目的変数を選択してモデル比較結果が表示されるまでコピーできません
  • 送信前にパネルの「Geminiへの送信内容を確認」を開き、個人情報・機密情報がないことを確認するチェックが必要です
  • プレビューを無効にしても、列名・クラス名・要約統計・分析結果は送信されます
  • APIキー有効時は、生成した解釈や分析文脈をもとに「この結果をレポート用に短く書くと？」のような追加質問ができます
  • 解釈は6節の構造化JSONとして受信し、型、項目数、文字数を検証してから表示します
  • 回答の末尾で、実際に使われたモデル、総トークン数、互換モデルへの切替を確認できます
  • 指定したGeminiモデルが利用できない場合だけ、安定版gemini-3.6-flashへ自動で切り替えます
  • APIキーはJavaScriptのメモリ内にだけ保持され、再読み込みまたはページを閉じると消えます
  • Interactions APIへの全送信で履歴保存を要求しないstore=falseを指定し、追加質問の履歴はページメモリ内だけで管理します
  • Googleは2026年9月からStandard keyを拒否するため、Google AI StudioのAuth keyを使用してください
  • 入力データは信頼できない文脈として区切られますが、個人情報・機密情報は送信しないでください
  • 生成AIの説明には誤りがあり得ます。元の指標、データ、授業資料と照合してください

12. モデル保存と予測モード

回帰・分類でファイナライズしたモデルは JSON ファイルとして保存できます。保存済みモデルはトップ画面の「モデル読み込み＆予測」から利用します。

  1. JSON モデルファイルをアップロードする
  2. モデル名、タスク、目的変数、特徴量数を確認する
  3. 表示された入力フォームに新しい特徴量を入力する
  4. 「予測を実行」を押す

13. 画像分類（MobileNet）

CSVデータを使わず、画像ファイルを直接アップロードして分類モデルを作ります。

2クラス以上 各クラス最低2枚 JPEG / PNG / WebP 1枚15 MiB以下・各クラス200枚まで
  1. クラスを追加する
  2. 各クラスに画像をアップロードする
  3. エポック数と検証データ割合を選ぶ
  4. 学習を実行する
  5. 層化された未学習データの評価結果、学習曲線、クラス別再現率、混同行列を確認する
  6. 新しい画像をアップロードして分類する
検証データは学習曲線やモデル設定の確認にも使うため、最終的な独立テストではありません。別の撮影条件で再評価してください。

14. 音声分類（Web Audio）

マイク録音または音声ファイルからサンプルを集め、スペクトル特徴量を使って分類モデルを学習します。

2クラス以上 各クラス2サンプル以上 3秒程度のクリップ 1件25 MiB・30秒以下・各クラス100件まで
  1. クラス名を入力して追加する
  2. 各クラスで録音または音声サンプルをアップロードする
  3. 学習を開始する
  4. 層化された未学習データの評価結果、クラス別再現率、混同行列を確認する
  5. 新しい音声を録音またはアップロードして分類する
マイク利用時はブラウザのマイク許可が必要です。検証データは最終的な独立テストではなく、周囲の雑音や録音機器が変わると性能も変わります。

15. 動画・画像分析

ローカルの動画や静止画をブラウザ内で再生・観察し、スポーツや動作を記録・比較します。

動画 / 静止画 描画・タグ・2画面比較 MoveNetポーズ推定
  1. 動画または画像を読み込み、再生・速度・コマ送りで観察する
  2. 線や図形を描き、動画では表示時刻と秒数を設定する
  3. 動画の出来事をタグで記録し、CSVへ書き出す
  4. 必要に応じて2つの動画を並べ、オフセット付きで同期比較する
  5. MoveNetで骨格と関節角度を推定し、結果と限界を確認する
メディアは外部送信されません。アノテーションJSONは5 MiB以下で、読込時に形式と件数を検証します。ポーズ推定は遮蔽、画角、衣服、複数人により誤ることがあります。

16. 結果の見方

  • モデル選択は前処理込み交差検証で行い、テストデータは候補確定後に一度だけ開示する
  • fold間SDは信頼区間ではなく、分割による変動の目安として見る
  • 回帰では R2 だけでなく、目的変数と同じ単位の MAE と RMSE も確認する
  • 回帰の新規入力に表示される値は点予測であり、個別の将来観測に対する予測区間ではない
  • 分類では Accuracy だけでなく Macro F1、クラス別 Precision / Recall、混同行列を確認する
  • 特徴量重要度は因果関係の証明ではなく、モデル解釈のヒントとして使う
  • 欠損、外れ値、カテゴリ表記ゆれ、クラス不均衡を確認する
  • カテゴリ特徴量は各訓練区画でOne-Hot Encodingされ、未知カテゴリは全0になる。未知カテゴリが多い場合はデータ収集やカテゴリ設計を見直す
  • 時系列、同一人物の反復測定、学校・施設などのグループ構造がある場合は、専用の時系列分割またはグループ分割を使う

17. よくあるトラブル

ファイルが読み込めない

拡張子、1行目の列名、空行、セル結合、装飾用の見出し行を確認してください。

分析カードが押せない

カードごとに必要なデータ条件があります。回帰は数値の目的変数と別の特徴量、分類は2〜20種類の値を持つ目的変数候補と別の特徴量が必要です。

数値列が特徴量として使えない

80点、約60、1,000、全角数字などが混ざっていないか確認してください。

画像・音声分類がうまく学習しない

各クラスのサンプル数、クラス間の偏り、撮影・録音条件、背景や雑音の違いを確認してください。

18. 分析前チェックリスト

  • 目的変数を決めた
  • 目的変数が数値なら回帰、カテゴリなら分類を選ぶと決めた
  • 1行目が列名だけになっている
  • セル結合や装飾用の見出し行がない
  • 数値列に単位や文字が混ざっていない
  • 欠損値と外れ値を確認した
  • クラス不均衡を確認した
  • モデル選択前にテストデータを開示しない
  • 時系列・反復測定・グループ構造の有無を確認した
  • モデル保存が必要な場合はファイナライズ後に JSON をダウンロードする
