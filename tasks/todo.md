# Iteration 13: モデル別の性能・係数表示改善

## 目標
分析結果に表示される係数・性能指標を、学習アルゴリズムごとの意味に合わせて整理し、学習者が誤解しにくい診断表示を追加する。

## タスク

- [x] 1. 既存の性能・係数・重要度表示を確認する
- [x] 2. 回帰結果にベースライン比較・残差診断・モデル別診断を追加する
- [x] 3. 分類結果にベースライン比較・クラス別指標・モデル別診断を追加する
- [x] 4. 小規模データでAdjusted R²がモデル失敗扱いになる問題を修正する
- [x] 5. 静的チェックと差分レビューを実施する
- [x] 6. 結果と残リスクを記録する

## 成功基準

- 線形系モデルでは係数を標準化後係数として表示し、カテゴリLabel Encodingの注意を示す
- 木系・ランダムフォレスト・GBMでは係数ではなく特徴量重要度と主要パラメータを表示する
- KNN・Naive Bayes・SVMでは係数/確率の意味を誤解しない注釈を表示する
- 性能指標に単純ベースライン比較とクラス別/残差診断を含める
- `node --check` と `git diff --check` が通る

## レビュー

- 回帰の詳細評価に「性能の妥当性チェック」を追加し、訓練平均ベースラインとのR²/MAE/RMSE比較、残差平均、残差標準偏差を表示するようにした。
- 回帰のモデル別診断を追加した。Linear/Ridge/Lassoは標準化後係数、Tree/RF/GBMは特徴量重要度と主要パラメータ、KNNは近傍数と距離ベースの注意を表示する。
- 分類の詳細評価に「性能の妥当性チェック」を追加し、多数派クラスベースラインとのAccuracy/Macro Precision/Macro Recall/Macro F1比較、クラス別Precision/Recall/F1を表示するようにした。
- 分類のモデル別診断を追加した。LRはlog-odds係数、SVMはマージン重みと未キャリブレーション確率の注意、Tree/RF/GBMは特徴量重要度、KNNは近傍法の注意、NBは事前確率と分布仮定を表示する。
- CV表示を「参考値」と明示し、前処理後データのCVであること、finalize後の全データCVは独立テスト評価ではないことを画面文言に反映した。
- Adjusted R²は計算不能な小規模データでは非表示にし、モデル全体を失敗扱いにしないようにした。
- `node --check js/analyses/regression.js` と `node --check js/analyses/classification.js` は成功。
- ES module import確認は警告のみで成功。
- `git diff --check` は成功。
- 残リスク: ブラウザでの視覚確認は未実施。前処理込みCVの根本修正、乱数モデルの完全再現性対応は今回の表示改善とは別課題として残る。
