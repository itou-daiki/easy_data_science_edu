# Iteration 10: HTMLマニュアル表示対応

## 目標
easyStat と同様に、トップページの「使い方マニュアル」リンクから専用HTMLマニュアルを表示できるようにする。

## タスク

- [x] 1. easyStat 形式のマニュアル導線を確認する
- [x] 2. `manual.html` の構成を設計する
- [x] 3. HTML版マニュアルを作成する
- [x] 4. トップページのリンク先を `manual.html` に変更する
- [x] 5. README と整合性を取る
- [x] 6. 静的チェックとレビュー記録を行う

## 成功基準

- ページトップの「使い方マニュアル」が Markdown ではなく HTML マニュアルを開く
- HTMLマニュアルにアプリへ戻る導線がある
- サイドバーから主要章へ移動できる
- 既存の Markdown マニュアルも補助資料として残る
- 変更内容がこのファイルに記録されている

## レビュー

### 作成内容

- `manual.html` を新規作成し、easyStat と同様に固定トップナビ、左サイドバー、章別本文を持つHTMLマニュアルとして表示できるようにした。
- `index.html` のページトップ右上「使い方マニュアル」リンクを `USAGE_MANUAL.md` から `manual.html` に変更した。
- `README.md` はHTML版マニュアルを主リンク、Markdown版を補助資料として案内する形に更新した。

### 検証

- `rg` で `index.html` から `manual.html` へのリンク、`manual.html` の「アプリへ戻る」導線、サイドバー要素が存在することを確認した。
- `git diff --check` で空白エラーがないことを確認した。
- ローカルサーバー経由の `curl` 確認を試したが、この実行環境では接続できなかったため、確認用サーバーは停止した。
