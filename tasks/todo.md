# Iteration 20: AI用テキストコピーの利用条件制御

## 目標

回帰・分類の目的変数を選択して分析結果が生成される前に、「AI用テキストをコピー」が実行できないようにする。コピーされるAI文脈が、データ概要だけでなく選択変数・分析手法・結果を含む状態に限定されるようにする。

## タスク

- [x] 1. 現行のAI補助パネルとコピー機能の有無を確認する
- [x] 2. AI補助パネルにAI用テキストコピー操作を追加する
- [x] 3. 回帰・分類の初期表示ではコピー不可のAI補助パネルを表示する
- [x] 4. 分析結果表示後はコピー可能な文脈へ切り替える
- [x] 5. 静的チェックと差分確認を実施する

## 成功基準

- 回帰・分類で目的変数選択前にAI用テキストコピーが押せない
- 分析結果表示後はAI用テキストをクリップボードへコピーできる
- コピー内容はGemini送信用と同じ分析文脈を含む
- `node --check` と `git diff --check` が通る

## レビュー

- 現行コードには「AI用テキストをコピー」のUIが未実装だったため、AI補助パネルにコピー操作を追加した。
- コピー内容はGeminiに送るプロンプトと同じ `buildPrompt(context)` を使うようにした。
- `renderAIAssistPanel()` に `ready` と `unavailableReason` を追加し、分析文脈が未完成のときはコピーと生成ボタンを無効化できるようにした。
- 回帰・分類の初期表示では、目的変数未選択の説明付きでAI補助パネルを表示し、コピー不可にした。
- モデル比較結果の詳細表示後は、既存の分析結果文脈でAI補助パネルが再描画されるため、コピー可能になる。
- `node --check js/ai_assistant.js`、`node --check js/analyses/regression.js`、`node --check js/analyses/classification.js` は成功。
- ES module import確認は既存のMODULE_TYPELESS警告のみで成功。
- `git diff --check` は成功。
